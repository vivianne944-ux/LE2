Pharmacology LE2 · 2027–2028 Question Categorizer

Every uploaded question is preserved and mapped to the LE2 lecture set when supported. Questions outside that lecture set are separated rather than silently forced into a lecture. Repeat families highlight what the examiners keep recycling.

Source boundary: Historical questions and rationales come from the uploaded 2027 and 2028 Q2 Pharmacology PDFs. The “in lecture set” classification uses the six LE2 lecture categories already provided in this project (2.01–2.06). Antimicrobial and prescription-writing material is labeled Outside current LE2 lecture set. No outside web material was added.

Built as a self-contained study file. Source keys are preserved exactly when supplied. Internal source conflicts and extraction problems are flagged instead of silently corrected.
